# Алгоритм работы пайплайна research-agents на Gemini

## Цель исследования
Разработка математической модели для оценки интенсивности изнашивания зубчатой передачи опорно-поворотного устройства (ОПУ) судовых кранов с учётом динамических нагрузок, вызванных движением судна, массой стрелы и груза, а также применения полимерных композиционных материалов (ПКМ).

---

## Этап 1: ResearchAgent (Литературный обзор)

### Входные данные:
- `research_goal.txt` — текст цели исследования на русском
- `agent_config.yaml` — конфиг с параметрами поиска:
  - `sources`: [arxiv, semantic_scholar, mdpi]
  - `max_papers`: 25
  - `language`: en

### Процесс:

**1.1. Генерация поисковых запросов**
- **Компонент:** QueryBuilder (с LLM Gemini)
- **Действие:** На основе `research_goal.txt` генерирует 6 англоязычных поисковых запросов
  - Запросы должны покрывать:
    - Износ зубчатых передач
    - Динамические нагрузки в кранах
    - Трибологические модели
    - Материалы и композиты
    - GLM модели для предсказания
    - Стандарты DNV/RMRS
- **Выход:** список из 6 запросов (JSON)

**1.2. Поиск статей**
- **Компоненты:** ArxivSearcher, SemanticScholarSearcher, MdpiSearcher
- **Действие:** Для каждого запроса ищет статьи в 3 источниках
  - Max ~4 статьи на запрос на источник → ~72 статьи всего
  - Уникализация по DOI/Title → ~30-50 уникальных
- **Выход:** список Paper объектов с title, abstract, authors, year, doi

**1.3. Анализ релевантности статей**
- **Компонент:** PaperAnalyzer (с LLM Gemini)
- **Действие:** Для каждой статьи анализирует:
  - Проходит ли domain filter (относится ли к проблеме)?
  - Relevance score (0-1)
  - Категория (teoria, experimental, standards, tools, other)
  - Краткое резюме
  - Ключевые уравнения
  - Пробелы в исследовании (gap analysis)
- **Выход:** PaperAnalysis с доп. информацией для каждой статьи

**1.4. Фильтрация релевантных статей**
- **Действие:** Оставляет только статьи с `passes_domain_filter=True`
- **Требование:** Минимум 5 релевантных статей, иначе ошибка
- **Выход:** список релевантных PaperAnalysis

**1.5. Синтез литературного обзора**
- **Компонент:** Synthesizer (с LLM Gemini)
- **Действие:** Для каждой категории статей (teoria, experimental, etc.):
  - Генерирует раздел литературного обзора (Markdown)
  - Использует резюме, уравнения, gaps из анализа
  - На русском языке (по промпту)
- **Выход:** Markdown разделы обзора

**1.6. Экспорт результатов**
- **Файлы:**
  - `literature_review.md` — полный обзор на русском
  - `references.bib` — BibTeX со всеми статьями
  - `papers.json` — структурированные данные всех статей с анализом

### Выходные артефакты:
```
output/
├── literature_review.md    ✓ Обзор литературы (русский)
├── references.bib          ✓ Библиография
└── papers.json            ✓ Данные статей
```

## Конфигурация Gemini

### .env переменные:
```
GEMINI_API_KEY=<ключ от Google>
AI_MODEL_NAME=gemini-2.0-flash (или другая модель Gemini)
GEN_TEMPERATURE_CREATIVE=0.8      # Для синтеза текста
GEN_TEMPERATURE_ANALYTICAL=0.5    # Для анализа
GEN_TEMPERATURE_DETERMINISTIC=0.2 # Для вычислений
```

### Используемые модели Gemini:
- **gemini-2.0-flash** — основная модель (быстрая, дешевая)
- Альтернативы: gemini-pro, gemini-1.5-flash

### Температурные настройки по компонентам:

| Компонент | Температура | Причина |
|-----------|------------|---------|
| QueryBuilder | 0.7 | Вариативность запросов, но не слишком хаотичность |
| PaperAnalyzer | 0.5 | Стабильная классификация |
| Synthesizer | 0.7-0.8 | Творческое написание |
| PaperExtractor | 0.5 | Точное извлечение данных |
| StandardsCalculator | 0.2 | Детерминированные расчеты |
| EngineeringCalculator | 0.2 | Детерминированные расчеты |

## Команда запуска

```bash
python main.py \
  --goal research_goal.txt \
  --config agent_config.yaml \
  --output ./output
```

### Ожидаемое время:
- Генерация запросов: ~10 сек
- Поиск в 3 источниках: ~30-60 сек
- Анализ 30-50 статей: ~3-5 минут
- Синтез обзора: ~1-2 минуты
- **Итого: 5-10 минут**

## Сверка результатов

### Успешный запуск:
- ✅ `literature_review.md` создан и содержит разделы
- ✅ `references.bib` содержит минимум 5 записей
- ✅ `papers.json` содержит массив анализов
- ✅ `run_context.json` показывает `"research": "completed"`

### Потенциальные ошибки:

| Ошибка | Причина | Решение |
|--------|---------|--------|
| "GEMINI_API_KEY not set" | Ключ не указан в .env | Вставить ключ из Google Cloud |
| "Insufficient relevant sources" | Найдено < 5 релевантных статей | Расширить `max_papers` или источники |
| "No papers found" | Поиск не работает | Проверить доступность источников (интернет) |
| JSON parse error | LLM вернул невалидный JSON | Повторить (обычно срабатывает со второй попытки) |
